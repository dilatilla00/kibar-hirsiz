# Game Center kurulumu (App Store Connect)

Bu klasördeki 27 görsel (1024×1024) başarımlar içindir. Dosya adı = başarım kimliği (`kh_ilk_is.png` → `kh_ilk_is`).

## Sıralamalar (Leaderboards)

Tür: **Classic**, Score Format: **Integer**, Sort: **High to Low**, Submission: **Best Score**.

| Leaderboard ID | Reference Name | Türkçe ad | English name |
|---|---|---|---|
| `kh_loot` | Toplam ganimet | Toplam ganimet | Total loot |
| `kh_level` | Seviye | Seviye | Level |
